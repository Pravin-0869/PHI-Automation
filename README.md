# PHI Automation

Automation testing project for the Prudential Health Insurance (PHI) application.

## Tech Stack

- Java
- Selenium WebDriver
- TestNG
- Maven
- IntelliJ IDEA
- ChromeDriver
- Git
- GitHub

## Project Purpose

This project is created to automate functional and regression testing of the PHI application using Selenium WebDriver with Java.

## Testing Areas

- Agent Login
- Agent Onboarding
- Quote Generation
- Customer Details
- KYC
- Proposal
- Insurer Details
- Nominee Details
- Medical Questions
- Summary
- Payment
- Thank You Page

## Automation Framework

The project follows the Page Object Model (POM) approach.

### Main Components

- Test Classes
- Page Objects
- Test Data
- Utilities
- TestNG
- Maven
- Configuration
- Reports

## Prerequisites

Make sure the following are installed:

- Java JDK
- Maven
- IntelliJ IDEA
- Google Chrome
- ChromeDriver
- Git

## Installation

Clone the repository:

git clone <your-repository-url>

Go to the project folder:

cd PHI-Automation

Install Maven dependencies:

mvn clean install

## Run Tests

Run all tests using Maven:

mvn test

Run tests from IntelliJ IDEA using TestNG.

## Test Reports

Test execution reports can be generated after the test execution depending on the reporting configuration used in the project.
